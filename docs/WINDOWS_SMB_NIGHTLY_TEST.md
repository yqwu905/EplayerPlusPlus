# Windows SMB Nightly A/B 测试

此测试版本的总开关默认关闭，首次启动行为与正式版一致。所有优化只对 Windows
UNC 路径（例如 `\\server\share\images`）和映射网络盘生效，本地磁盘不受影响。

## 开关位置

打开“设置 → 性能 → Windows 网络文件夹”：

1. “启用 Windows 网络文件夹优化（实验性）”是总开关。
2. “使用原生目录枚举并复用文件时间”减少 SMB 元数据请求。
3. “限制网络缩略图预取范围与并发”优先加载当前屏幕并避免预取淹没共享。
4. “启动时延后验证网络目录”避免离线共享在启动时卡住界面。

修改设置并保存后，已打开的网络图片列会自动重新扫描；无需重启应用。

## 推荐测试方法

使用同一个包含至少 500 张图片的 Samba 目录，分别执行传统模式和优化模式。
每种模式各测试三次，记录中位数：

- 从“加入对比”到第一张缩略图出现的时间。
- 从“加入对比”到当前屏幕缩略图全部出现的时间。
- 快速滚动五屏后，新屏幕缩略图稳定出现的时间。
- 断开网络后重新启动应用，主窗口可操作所需时间。
- 第二次打开同一目录时的时间，用于验证磁盘缩略图缓存命中。

为保证结果可比，传统模式与优化模式必须使用相同目录、相同缩略图列宽、相同网络连接，
并区分首次冷加载与第二次热缓存加载。若要单独判断某项优化的贡献，请保持总开关开启，
每次只关闭一个分项开关。

## 反馈信息

反馈时请附上：Windows 版本、Samba/NAS 型号或 Samba 版本、连接方式（有线/Wi-Fi）、
路径类型（UNC/映射盘）、图片数量和格式，以及上述各项的传统模式/优化模式中位数。
